# 黄璐漩的山野日记

一款无需外部素材的竖屏微信小游戏。玩家陪黄璐漩一路向上，躲开树桩与落石，收集山花恢复体力，最后在山顶迎接日出。

## 运行

1. 打开微信开发者工具，选择“小游戏”。
2. 导入本目录 `huang-luxuan-mountain`。
3. 没有 AppID 时可使用测试号；发布前把 `project.config.json` 中的 `appid` 替换为正式小游戏 AppID。
4. 点击“编译”即可体验。

## 操作

- 点击屏幕：起跳；在空中再次点击可二段跳。
- 收集山花：恢复 8 点体力并增加分数。
- 撞到障碍：损失 24 点体力。
- 赵云会从后方追赶；体力耗尽时，他会追上并推着黄璐漩快速走出屏幕。
- 完成三段旅程，抵达 1700 米山顶。

游戏会在本地记录最佳用时。

## 网页版

直接用浏览器打开 `index.html` 即可运行。若需要分享给他人，应将整个目录部署到任意静态网站服务，不能只上传单独的 HTML 文件。
